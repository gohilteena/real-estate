# Real Estate Property Listing

A responsive real estate property listing application built with React.js.  
The application displays property data from a JSON file and provides filtering, pagination, and a multi-step contact form.

## Features

- Property listing using JSON data
- Property Type and Developer filters
- Reset All Filters
- Pagination with 9 properties per page
- Contact Us popup
- 3-step contact form
- Name, email, and phone validation
- Responsive design

## Tech Stack

- React.js
- JavaScript
- HTML5
- CSS3
- Bootstrap
- Context API
- JSON
- react-phone-input-2
